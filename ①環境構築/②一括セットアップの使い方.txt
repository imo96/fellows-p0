■ 一括セットアップツールの使い方

このフォルダの setup.bat を実行すると、
 - [③ツール一覧.txt]の資材をすべてダウンロードし、[資材]フォルダに格納
 - [①手順.txt]の「１．資材をインストール」を自動実行
 - 作業フォルダ C:\fellowsapp を作成し、データベース(myappdb.sqlite3)を配置(デスクトップにショートカットを作成)
 ※既にインストールされているツールは自動でスキップします。


【実行】
　1. setup.bat をダブルクリック
　2. 「このアプリがデバイスに変更を加えることを許可しますか?」→［はい］
　3. 黒い画面に進み具合が表示されるので、終わるまで待つ(数分程度)
　4. 最後に表示される「結果」を確認する
　　　インストール完了 / 作成完了 …… 問題なし
　　　スキップ ………………… 既にインストール済み(何もしていない)
　　　失敗 ……………………… 手順.txt の手順で、そのツールだけ手動でインストールする
　5. 開いていたコマンドプロンプトや VS Code は一度閉じる(Path の変更を反映するため)

【自動で設定される内容】
　Python     全ユーザー版としてインストールし、Path に追加(データベースの SQLite は Python に組み込み済み)
　VS Code    全ユーザー版としてインストール、手順.txt の追加タスクをすべて ON、Python 拡張・日本語化も追加(拡張機能はログイン中のユーザーに追加)
　C:\fellowsapp   講義で生成したアプリを置く作業フォルダ。myappdb.sqlite3 をコピー(既にある場合は上書きしない)

【注意】
　・管理者権限のあるユーザーでログインして実行してください。
　　管理者権限のないユーザーで実行すると、管理者のパスワードを入力する画面が出ます。
　　Python と VS Code は全ユーザー版で入るので、ログイン中のユーザーからも使えます。
　・VS Code の拡張機能の追加にはインターネット接続が必要です。
　・myappdb.sqlite3 のコピー元は、①環境構築 フォルダの「商品関連テーブル」フォルダです。このフォルダを除いて setup.bat を実行すると、DB の配置に失敗します。
　・実行の記録はデスクトップの setup_log.txt に保存されます。
