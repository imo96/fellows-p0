# 講義用 環境構築ツール（①前準備リポジトリ）

このリポジトリには、講義の前に受講生が行う準備が入っています。

- **①環境構築**: 講義で使う開発環境を、受講生の PC に準備するツール（このページの内容）。データベース（SQLite）のファイルもここに入っています
- **②Claude利用開始**: Claude のアカウント（無料プラン）を作成する手順

受講生が講義の前に行うのは、**①環境構築** と **②Claude利用開始** の 2 つです。講義の教材（指示書、画面 HTML など）は、別の「②講義用リポジトリ」にあります。

## 講義の前に、準備を終わらせてください

環境構築には 5〜10 分ほどかかります（インターネット接続が必要です）。
**講義が始まる前に、各自で済ませておいてください。** 講義の時間は、環境構築ではなく、講義の内容に使います。

## 準備するソフトと入手先

必要なソフトは、次の場所から入手します。`setup.bat` が自動でダウンロードします。

| ソフト | 用途 | 入手先 |
|---|---|---|
| Python 3.12.10 | Python の開発(データベースの SQLite は Python に組み込まれています) | [公式サイト](https://www.python.org/downloads/release/python-31210/)（`setup.bat` が自動で取得します） |
| Visual Studio Code | Python の開発 | [公式サイト](https://code.visualstudio.com/download)（`setup.bat` が自動で取得します） |

データベース（SQLite）は、別のソフトをインストールする必要はありません。`setup.bat` が、作業フォルダ **`C:\fellowsapp`** を作り、データベースのファイル `myappdb.sqlite3` を置きます（デスクトップにも `fellowsapp` のショートカットができます）。講義で生成したアプリは、`C:\fellowsapp` に展開します。

## 環境構築の手順

1. [リポジトリのトップページ](https://github.com/imo96/fellows-p0) を開き、右上の緑のボタン［Code］→［Download ZIP］で、ZIP をダウンロードします。
   - ※［Code］ボタンは、トップページにだけ表示されます。①環境構築 フォルダの中のページには表示されないので、トップページに戻ってください。
2. ZIP を **「右クリック → すべて展開」** で展開します。展開先は、`C:\fellows` のように、**半角英数字だけの短いフォルダ**にしてください。
3. 展開したフォルダの中の **①環境構築** フォルダを開き、その中の **setup.bat** をダブルクリックします。
   - 「Windows によって PC が保護されました」と出たら、［詳細情報］→［実行］を押します。
   - 「このアプリがデバイスに変更を加えることを許可しますか?」と出たら、［はい］を押します。
4. 黒い画面に進み具合が表示されます。**終わるまで閉じずに待ってください。**
5. 最後に表示される「結果」を確認します。
   - 「インストール完了」「スキップ」「作成完了」…… 問題ありません。
   - 「失敗」…… そのまま講義で相談してください（下の「問題が発生した場合」を参照）。
6. 開いているコマンドプロンプトや VS Code は、いったん閉じます。

詳しい内容は、フォルダ内の「②一括セットアップの使い方.txt」を見てください。

## 環境構築のあとに（Claude の利用開始）

講義の前に、もう 1 つ、**Claude のアカウント（無料プラン）の作成**が必要です。
登録に電話番号の認証が必要になることがあり、講義の当日には間に合わない場合があります。

- 手順: [②Claude利用開始/claude開始手順.md](./②Claude利用開始/claude開始手順.md)

## ご注意

- **管理者権限のあるアカウント**でログインして実行してください。
- Windows のユーザー名に日本語（全角文字）が含まれていたり、フォルダのパスにスペースや特殊文字があったりすると、トラブルが発生しやすくなります。
- インストールした記録は、デスクトップの `setup_log.txt` に保存されます。
- すでにインストールされているソフトは、自動でスキップされます。

## 問題が発生した場合

環境構築で問題が発生しても、**講義の中で講師が対応します**。自分で解決できなくても、慌てずに、講義の時間に相談してください。
そのとき、画面の様子と、デスクトップの `setup_log.txt` を見せていただけると、原因を調べやすくなります。
